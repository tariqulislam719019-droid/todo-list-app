# My To-Do List App

A simple and responsive To-Do List application built with HTML, CSS, and JavaScript.

## Features

- Add new tasks
- Edit and delete tasks
- Mark tasks as completed
- Search tasks
- Dark mode
- Clear completed tasks
- Save tasks using LocalStorage
- Task counters

## Technologies Used

- HTML5
- CSS3
- JavaScript
- LocalStorage
